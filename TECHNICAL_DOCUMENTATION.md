## Under the Hood: How it Works

Android apps are built using Android Studio with languages like Kotlin or Java. I found Kotlin easier to understand.

In a basic Android project, there are different parts:

- Kotlin files → where we write the logic  
- XML files → where we design the UI  
- Gradle files → used for dependencies and setup  

When a user clicks a button:
- Button is written in XML  
- Action is handled in Kotlin  
- Then app gives response  

All these things connect together to make a working app.
